# 🏋️‍♂️ Academia API

API RESTful para gerenciamento de academias, desenvolvida como parte dos meus estudos focados em desenvolvimento backend fullstack.

## 🚀 Tecnologias Utilizadas

* **Node.js**
* **Express**
* **Biome**
* **PNPM**

## 📌 Funcionalidades Principais

- [x] Inicialização e configuração do servidor HTTP
- [ ] Modelagem e migrações do banco de dados (Em desenvolvimento)
- [ ] Autenticação de usuários
- [ ] Gestão de treinos e matrículas

## 💻 Como Rodar o Projeto

### Pré-requisitos
* Node.js (versão LTS recomendada)
* PNPM instalado globalmente

### Passo a Passo
1. *Clone o repositório:*
```bash
    git clone https://github.com/diogoguilherme-dev/academia-api.git
```

2. *Acesse a pasta do projeto:*
```bash
    cd academia-api
```

3. *Instale as dependências:*
```bash
    pnpm install
```

4. *Inicie o servidor de desenvolvimento:*
```bash
    pnpm run dev
```
